Privacy Policy for Personal Rclone Google Drive Integration Last updated: 12.10.2026 Overview This application/configuration is a private, non-commercial setup used exclusively by the owner to manage personal files on Google Drive using Rclone. It is not open for public use. Data Collection • Google User Data: The application accesses Google Drive data (such as files, folders, or metadata) only after explicit authorization by the Google account owner via OAuth 2.0. • Credentials & Tokens: OAuth access and refresh tokens are stored locally on the owner's private device (e.g., inside rclone.conf) and are never shared with any third parties. Data Usage • Data accessed from Google Drive is used solely to perform file transfer, backup, and synchronization operations initiated directly by the owner. • This application does not use Google user data for advertising, profiling, marketing, or training machine learning models. Data Sharing • No data is sold, rented, or shared with third parties. All file transfers occur directly between the local machine running Rclone and Google’s servers. Data Security • Authentication tokens and configuration files are kept secure on private devices controlled by the owner. Revoking Access • You can revoke access to your Google Drive data at any time through your Google Account Security Settings.
